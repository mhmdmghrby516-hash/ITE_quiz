# نسخة React الثابتة

هذه النسخة تعمل دون PHP أو MySQL. بيانات الموقع والتعديلات والنتائج تُحفظ محليًا في `localStorage` داخل المتصفح.

## التشغيل أثناء التطوير

```bash
npm install
npm run dev
```

## إنشاء نسخة النشر الثابتة

```bash
npm run build
```

بعد البناء يمكن استضافة محتويات مجلد `dist` على أي استضافة ملفات ثابتة.
